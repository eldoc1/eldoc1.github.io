Method

  
How I work a case

  
The order stays the same on every case, so the results can be repeated and defended.

  
    
    
  1. Identify
    Scope the incident and list every source that could hold evidence: disks, memory, logs, network captures, cloud accounts.
    2. 
    
  2. Preserve
    Isolate the device, record its state and stop anything that would change it. Volatile data goes first.
    3. 
    
  3. Collect
    Acquire disk images and memory captures behind a write blocker. Hash everything and log who handled it.
    4. 
    
  4. Examine
    Work on verified copies. Parse file systems, registries, event logs and browser data into searchable form.
    5. 
    
  5. Analyze
    Correlate artifacts into one timeline and test each theory against more than one source.
    6. 
    
  6. Report
    Write findings a non-technical reader can follow, with hashes, tool versions and steps to reproduce.
    7. 
  

  
Rule zero. Never analyze the original. Image it, hash it, verify the hash, then work on the copy. The frameworks behind this are ISO/IEC 27037 for handling digital evidence and NIST SP 800-86 for the examination process.
